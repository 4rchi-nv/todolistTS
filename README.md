# ZalogHub — список задач

Тестовое задание: список задач на React и TypeScript. Сборка через Vite, без сервера и сторонних UI-библиотек.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка и просмотр продакшен-версии:

```bash
npm run build
npm run preview
```

## Поведение

- Задача добавляется из поля ввода кнопкой или клавишей Enter. Пустая строка и строка из пробелов не сохраняются.
- Чекбокс переключает задачу между активной и выполненной. Выполненные зачёркнуты и приглушены.
- Кнопка «Удалить» убирает задачу.
- Фильтры: все, активные, выполненные.
- Список пишется в `localStorage` и остаётся после обновления страницы.

## Время

Около 45 минут.
